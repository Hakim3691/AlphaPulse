# AlphaPulse + ProactiveMS — Spec Traceability Matrix

Every requirement in [`AlphaPulse_Android_SPEC_V14-3.md`](AlphaPulse_Android_SPEC_V14-3.md) and [`UNIFIED_SPECIFICATION.md`](UNIFIED_SPECIFICATION.md)
appears below exactly once, with the code that implements it and the tests that
prove it.

**Why this file exists.** The baseline specification is 64 sections long, and the
unified ProactiveMS + AlphaPulse bridge adds 8 sections ($\S 65$–$\S 72$). Without a map,
nobody can tell whether "$\S 32$ Model Disagreement Engine" or "$\S 69$ ProactiveMS Walk-Forward Cancellation-First Invalidation Engine" is finished or merely
mentioned in a roadmap string. This table is that map, and CI checks that it
still covers all 64 baseline sections plus the unified bridge extensions (`Contract C-15`).

**Status key**

| Status | Meaning |
| :--- | :--- |
| **Done** | Implemented and covered by automated tests. |
| **Partial** | Core behaviour exists, but a listed sub-requirement is missing. |
| **Gap** | Not implemented yet. Tracked in the row itself. |
